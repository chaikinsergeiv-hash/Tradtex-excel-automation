# Простая схема работы с Git

## Первый раз

1. Создать приватный репозиторий на GitHub.
2. Добавить содержимое этой папки.
3. Сделать первый commit:
   `Initial working WB automation`
4. Push.

## Когда скрипт изменился

1. Проверить его вручную.
2. Если работает — сохранить файл.
3. В GitHub Desktop посмотреть изменения.
4. Написать короткий комментарий, например:
   `Fix FBS CSV locking`
5. Commit.
6. Push.

## Зачем это нужно

Git хранит историю. Поэтому не нужно создавать файлы:
`v2`, `v3`, `v4`, `v5`...

Рабочий файл может всегда называться одинаково, а предыдущие версии остаются в истории Git.
