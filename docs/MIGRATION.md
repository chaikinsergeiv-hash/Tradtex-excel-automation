# Перенос на другой компьютер

## 1. Получить код

Самый простой вариант для начинающего — GitHub Desktop:

1. Установить GitHub Desktop.
2. Войти в GitHub.
3. `File -> Clone repository`.
4. Выбрать приватный репозиторий `wb-automation`.
5. Выбрать локальную папку.

## 2. Создать секретные файлы

Для остатков:

`stocks\wb_token.txt`

Для рекламы:

`advertising\wb_adv_token.txt`

Токены вставляются одной строкой без кавычек.

## 3. Проверить вручную

Сначала запускать `.cmd` двойным щелчком.

Только после успешной проверки создавать задания в Планировщике Windows.

## 4. Планировщик

В задаче указывать путь к `.ps1`, а не к `.cmd`.

Пример программы:

`powershell.exe`

Пример аргументов:

`-NoProfile -ExecutionPolicy Bypass -File "C:\Путь\wb-automation\stocks\WB_FBS_Stocks.ps1"`

Если репозиторий лежит на сетевом ресурсе, убедитесь, что учётная запись задачи имеет доступ к нему.
