# WB Advertising

Эта папка содержит только подтвержденные рабочие инструменты для рекламного API Wildberries.

## Файлы

- `WB_Ads_API_Raw_Dump.ps1` — рабочая выгрузка структуры рекламного API в RAW JSON и удобные CSV-файлы для анализа.
- `Запустить_WB_Реклама_RAW.cmd` — запуск RAW-выгрузки.
- `WB_Ads_RateLimit_Diagnostic.ps1` — диагностика токена и лимитов рекламного API.
- `Запустить_Диагностику_WB_Реклама.cmd` — запуск диагностики.
- `wb_adv_token.example.txt` — пример файла токена.

## Токен

Создай рядом локальный файл:

`wb_adv_token.txt`

и вставь в него персональный токен Wildberries категории **Продвижение**.

Настоящий токен не хранится в GitHub и исключен через `.gitignore`.

## Рекомендуемый порядок проверки на новом устройстве

1. Создать `wb_adv_token.txt`.
2. Запустить `Запустить_Диагностику_WB_Реклама.cmd`.
3. Убедиться, что ответ API — `HTTP 200 OK`.
4. Запустить `Запустить_WB_Реклама_RAW.cmd`.
5. Проверить появление файлов:
   - `01_UPD_RAW.json`
   - `01_UPD_FLAT.csv`
   - `02_ADVERTS_RAW.json`
   - `02_ADVERTS_TOP.csv`
   - `03_FULLSTATS_SAMPLE_RAW.json`
   - `03_FULLSTATS_SAMPLE_FLAT.csv`

## Текущий статус

Финальный формат 7-дневного рекламного отчета пока не зафиксирован.
Сначала анализируем фактическую структуру API через RAW-выгрузку, затем согласуем итоговые столбцы и агрегирование.

## Остатки FBS

Рабочая выгрузка остатков находится отдельно в `stocks/`.
При изменениях рекламной части папка `stocks/` не должна затрагиваться.
