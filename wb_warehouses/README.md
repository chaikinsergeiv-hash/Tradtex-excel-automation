# WB — остатки по складам Wildberries

Отдельный блок проекта для выгрузки текущих остатков по конкретным складам WB.

## Принцип

Этот блок независим от:

- `stocks/` — FBS остатки продавца;
- `advertising/` — реклама;
- `analytics/` — воронка продаж.

Работа ведётся в отдельной папке, чтобы изменения не затрагивали уже утверждённые рабочие блоки.

## Токен

Используется токен WB API категории «Аналитика».

Для локального запуска создать рядом со скриптом:

`wb_analytics_token.txt`

В GitHub хранится только шаблон без реального токена.

## Планируемый результат

Одна строка = один артикул WB.

Колонки:

- Артикул WB
- Артикул продавца
- Наименование
- отдельная колонка на каждый склад WB
- Итого WB

Если один артикул имеет несколько размеров/ChrtID, остатки по ним суммируются внутри артикула по каждому складу.

## Этап разработки

Сначала делаем диагностический запрос и смотрим реальную структуру ответа кабинета. После проверки фиксируем состав CSV и рабочий скрипт.
