# WB — цены и скидки

Отдельный блок проекта для выгрузки и дальнейшего управления ценами и скидками Wildberries.

## Токен

Используется отдельный токен WB API категории:

`Цены и скидки`

Файл локально:

`wb_prices_token.txt`

В GitHub хранится только шаблон без реального токена.

## Первый этап

Сначала делаем только чтение данных, без изменения цен.

Метод:

`GET https://discounts-prices-api.wildberries.ru/api/v2/list/goods/filter`

Он возвращает товары продавца с:

- nmID;
- vendorCode;
- currencyIsoCode4217;
- discount;
- clubDiscount;
- editableSizePrice;
- sizes;
- price по размеру;
- discountedPrice;
- clubDiscountedPrice.

Для всех товаров используется пагинация `limit=1000` + `offset`.

## Безопасность

На диагностическом и первом рабочем этапе скрипт ничего не меняет в кабинете WB.

Методы установки цен и скидок будут добавляться только отдельным этапом после проверки выгрузки.


## Оптовые скидки B2B

В итоговую выгрузку обязательно включаем информацию об оптовых скидках для юридических лиц / бизнеса.

Методы получения цен возвращают массив:

`wholesaleDiscountThreshold`

Если массив отсутствует или пустой — оптовая скидка B2B для товара не настроена.

Элемент массива содержит:

- `level` — уровень оптовой скидки;
- `minQuantity` — минимальное количество товара для этого уровня;
- `wholesaleDiscount` — размер оптовой скидки, %.

В итоговом CSV планируем отдельные поля:

- `B2B скидка есть` — Да/Нет;
- `B2B уровней` — количество уровней;
- динамические поля по каждому уровню:
  - `B2B уровень 1 от, шт`;
  - `B2B уровень 1 скидка, %`;
  - `B2B уровень 2 от, шт`;
  - `B2B уровень 2 скидка, %`;
  - и далее, если уровней больше.

Это позволит видеть не только факт наличия скидки, но и реальные условия оптовой цены.


## Диагностика

Добавлен безопасный тест:

`Запустить_WB_Цены_Диагностика.cmd`

Перед запуском:

1. скопировать `wb_prices_token.example.txt` в `wb_prices_token.txt`;
2. вставить токен категории «Цены и скидки»;
3. запустить CMD.

Диагностика делает ровно один запрос:

`GET /api/v2/list/goods/filter?limit=10&offset=0`

То есть максимум 10 товаров и только чтение данных.

Результаты:

- `01_WB_PRICES_RAW.json` — сырой ответ WB;
- `01_WB_PRICES_SAMPLE.csv` — тестовый CSV.

В тестовом CSV уже проверяются:

- nmID;
- артикул продавца;
- валюта;
- обычная скидка;
- скидка WB Клуба;
- возможность цен по размерам;
- B2B скидка есть/нет;
- количество B2B уровней;
- условия B2B скидок;
- цены по размерам.


## Рабочая выгрузка

Добавлен итоговый тестовый запуск:

`Запустить_WB_Цены_Скидки.cmd`

Он только читает данные и ничего не меняет в кабинете WB.

Основная логика:

- получает все товары через `GET /api/v2/list/goods/filter`;
- использует пагинацию `limit=1000` + `offset`;
- одна строка итогового CSV = один `nmID`;
- если у товара несколько размеров, цены сворачиваются в диапазоны `от/до`;
- дополнительно сохраняется контрольное текстовое поле `Цены по размерам`;
- обычная скидка и скидка WB Клуба выводятся отдельными колонками;
- оптовые B2B скидки определяются по `wholesaleDiscountThreshold`;
- уровни B2B разворачиваются в отдельные динамические колонки;
- если у товара B2B скидки нет, поле `B2B скидка есть` = `Нет`.

Рабочий итоговый файл:

`WB_Цены_Скидки.csv`

Основные колонки:

- Артикул WB
- Артикул продавца
- Валюта
- Скидка, %
- Скидка WB Клуба, %
- Цена базовая от / до
- Цена после скидки от / до
- Цена WB Клуб от / до
- Размеров
- Цены по размерам различаются
- Цена по размерам разрешена
- B2B скидка есть
- B2B уровней
- B2B уровень N от, шт
- B2B уровень N скидка, %
- B2B условия
- Цены по размерам

CSV:

- разделитель `;`;
- кодировка Windows-1251;
- без служебной строки `sep=;`.

В диагностическом RAW подтверждено, что B2B может содержать несколько уровней, например 5 шт = 3%, 15 шт = 4%, 30 шт = 5%.


## Зафиксированная рабочая версия

Версия подтверждена и принята как рабочая.

Основная логика:

- только чтение данных, без изменения цен и скидок в кабинете WB;
- одна строка итогового CSV = один `nmID`;
- все товары загружаются с пагинацией `limit=1000` + `offset`;
- базовые цены, цены после скидки и цены WB Клуба сворачиваются в диапазоны `от/до`;
- при наличии нескольких размеров сохраняется контрольное поле `Цены по размерам`;
- обычная скидка и скидка WB Клуба выводятся отдельно;
- B2B скидки для юрлиц/оптовиков читаются из `wholesaleDiscountThreshold`;
- каждый B2B уровень выводится в отдельные колонки `от, шт` и `скидка, %`;
- дополнительно сохраняется текстовое поле `B2B условия`;
- CSV записывается с разделителем `;` в Windows-1251, без строки `sep=;`.

Рабочий файл:

`WB_Цены_Скидки.csv`
