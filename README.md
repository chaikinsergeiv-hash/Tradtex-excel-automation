# WB Automation

Набор PowerShell-скриптов для автоматизации работы с Wildberries API.

## Что здесь есть

### `stocks/`
Рабочая выгрузка FBS-остатков по складам.

Схема:

`Content API -> Marketplace API -> CSV -> Excel Power Query`

Основной файл: `WB_FBS_Stocks.ps1`.

### `advertising/`
Инструменты для рекламного API.

- `WB_Ads_API_Raw_Dump.ps1` — подтверждённый рабочий скрипт для просмотра сырой структуры API.
- `WB_Ads_RateLimit_Diagnostic.ps1` — диагностика лимитов API.
- `WB_Ads_7days_EXPERIMENTAL.ps1` — текущий алгоритм итоговой 7-дневной рекламной статистики. Пока помечен как experimental до окончательной проверки результата.

## Токены

Настоящие токены **никогда не сохраняются в Git**.

После скачивания репозитория создайте локально:

- `stocks/wb_token.txt`
- `advertising/wb_adv_token.txt`

На основе файлов `*.example.txt`.

Файлы токенов перечислены в `.gitignore`.

## Новый компьютер

1. Скачать/клонировать репозиторий.
2. Создать локальные файлы токенов.
3. Проверить ручной запуск `.cmd`.
4. Настроить Планировщик заданий Windows.
5. Подключить выходной CSV в Excel через Power Query.

## Другой кабинет WB

Код можно использовать тот же. Создайте отдельную копию рабочей папки или отдельную конфигурацию и положите в неё токен нужного кабинета.

Не коммитьте CSV, логи и токены.
